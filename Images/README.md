# X Barbershop haircut photos

Upload haircut photos into this folder.

Then open `gallery.js` and add each image to the `photos` array, for example:

```js
{src:"Images/skin-fade-01.jpg",caption:"Skin fade",alt:"Fresh skin fade at X Barbershop"}
```

Use the exact filename and capitalisation. Commit and push both the image and the `gallery.js` update. Only publish photos you have permission to use.
